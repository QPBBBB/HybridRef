# 对齐数值示例

## 图片右侧放文本

A 是图片，`x=120,y=80,width=360,height=240`。B 是文本，`width=320,height=160`。目标是右侧间隔 24，并垂直居中：

```text
B.x = 120 + 360 + 24 = 504
B.y = 80 + (240 - 160)/2 = 120
```

把 B 的 config 改为 x=504、y=120，或调用 `element update` 传入这两个值。此计算已包含在 [Walkthrough.ps1](../Elements/Examples/Walkthrough.ps1) 中，会读取实际元素而不是依赖硬编码布局。后面的直接 YAML 示例另将文本移动 `(24,16)`，最终坐标为 `(528,136)`。

## 两张图片等宽并保持中心

A=`(0,0,200,100)`，B=`(300,40,400,300)`。目标平均宽度 300：

```text
A: scale=1.5  => width=300, height=150, x=-50, y=-25
B: scale=0.75 => width=300, height=225, x=350, y=77.5
```

## 左推保持分行

A=`(100,0,100,100)`，B=`(300,20,80,80)`，C=`(400,200,120,60)`。

选区左边为 100。A 保持 x=100；B 与 A 的 y 区间重叠，贴在 A 右边，x=200；C 与它们的 y 区间不重叠，可以到 x=100。三个元素的 y 和尺寸都不变。
