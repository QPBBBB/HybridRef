# 对齐计算方法

先读取所有参与元素的当前位置与尺寸，在内存中计算全部目标坐标，再逐个写入位置。不要每写一个元素就重新计算整体参考边界，否则后续结果会随写入顺序变化。

## 常用排版公式

相对参考元素 A 对齐 B：

| 效果 | B 的新坐标 |
| --- | --- |
| 左边对齐 | `B.x = A.x` |
| 右边对齐 | `B.x = A.x + A.width - B.width` |
| 顶边对齐 | `B.y = A.y` |
| 底边对齐 | `B.y = A.y + A.height - B.height` |
| x 中心一致 | `B.x = A.x + (A.width - B.width)/2` |
| y 中心一致 | `B.y = A.y + (A.height - B.height)/2` |
| 放在右侧，间隔 G | `B.x = A.x + A.width + G` |
| 放在下方，间隔 G | `B.y = A.y + A.height + G` |

只修改所需轴，保留另一个轴的位置和元素尺寸。边缘/间隔公式是通用排版方法，不表示应用已经提供同名按钮或命令。

## 与应用现有行为一致的规则

H（水平方向中心对齐）统一 **x 中心**：`x_i = L + (R-L-width_i)/2`。V 统一 **y 中心**：`y_i = T + (B-T-height_i)/2`。L/T/R/B 来自操作前的选中矩形联合边界。

向左/右/上/下推齐：保留尺寸和另一个轴，只沿指定轴消除空隙。以操作前选区外边为最远边界，从靠近推动方向的元素开始处理。只有在垂直于移动轴的区间有正长度重叠的元素才相互阻挡；边刚好相触不算重叠。依次让元素贴住已处理的阻挡元素，间距为 0。不能把所有元素简单设成同一个 x 或 y，这会产生重叠。

例如左推时按原 left 从小到大排列；候选 x 从选区 L 开始，与该元素 y 区间重叠的已排元素，其 right 都是候选下限，取最大值。右推镜像处理；上/下推交换 x/y 和 width/height。移动轴的边缘相同时，按另一轴的起点从小到大排列；仍相同才保留原顺序。

当前 UI 的 H/V、方向推齐、等宽等高面向选中的图片；agent 可把通用矩形公式用于文本布局，但不要因此改变字号。没有单独的 CLI 对齐命令：用 `element update` 提交算出的结果即可。
