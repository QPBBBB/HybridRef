# HybridRef

- Current scope: a minimal image-and-text reference board with editable connector arrows. Citadel is a reference, not the active application.
- Runs directly in the user's browser. React/TypeScript UI plus a Node.js service bound to 127.0.0.1; no Electron in the active application. Infinite canvas, multi-select, snapping, alignment, pan/zoom, image resize, clipboard, delete and undo/redo.
- Source: `Code/Module`; portable Windows x64 Node.js, pnpm and dependencies: `Dependencies/`; active icons and demo inputs: `Code/Resource`. All subdirectories and filename stems under `Code/Resource` must use PascalCase; retain only assets used by the active application or its development scripts. `Code/Module/node_modules` is a local junction to `Dependencies/Packages/node_modules`, repaired by the environment scripts after relocation. Previous Citadel implementation is archived in `Code/Module/reference/citadel` and excluded from builds/tests.
- Text items are editable resources stored beside PNGs. Do not add multiple boards, media players, recording, transcription, plugins or onboarding.
- Native document version 3 stores text layout and resource references only. Text content and styles live in separate `Text_<16 uppercase timestamp hash>_<8 uppercase content hash>.yaml` resources. Preserve version 1 rejection. Publish resources before atomically replacing the project file, then remove orphan resources; do not retain historical assets. Text copies have independent IDs and editable content.
- Boards containing arrows use native document version 4 so older services reject rather than silently discard them. Keep reading versions 2/3; write version 3 when no arrows remain. Store connector geometry, style and optional endpoint bindings inline in `arrows`; no raster asset is needed. Provide a fixed-size left-side creation icon, drag-to-draw orthogonal paths, editable endpoints/middle leg, and an adaptive white gear centered above the arrow's AABB opening a non-modal color/width/solid-or-dashed card. A single selected arrow has endpoint/bend handles without an AABB selection/resize box; retain group transforms for mixed selections. Use the supplied gear PNG as an alpha mask. Bound endpoints follow image/text movement and resizing; group copies remap bindings to copied IDs, standalone copies detach, and deleting targets retains the arrow with detached endpoints. Preserve mixed selection, transforms, Space fit, PNG snapshots, save/cleanup, and undo/redo. Keep arrow SVG geometry shared between canvas and snapshots: the visible shaft stops at the triangle base with a butt cap, while hit testing and endpoint handles retain the actual tip. Do not add a graphics framework.
- Selected images/text show four circular connection handles outside their edge centers. Drag directly from a handle to create a bound line without entering the toolbar tool; reveal target handles during drawing or endpoint reconnection, highlight the snapped target, and store centered bindings (offset 0.5). Keep handle hit areas, outside spacing and snap tolerance constant in screen pixels. Preserve existing saved offsets. Follow port directions in the orthogonal route and include the complete route in its frame. A click/tiny drag does not create a line; Escape/pointer cancellation restores the source selection, and Space + drag still pans. Hide connection controls during inline text editing and omit them from PNG snapshots.
- Text creation, content/style editing, geometry, clipboard, selection, undo/redo and unsaved-state tracking must work with images. Preserve native text editing, multiline content and Chinese IME input; do not reuse the existing T shortcut for text creation.
- Tap unmodified Space to center and fit selected images/text within the canvas, preserving object geometry and selection; no selection means no viewport change. Trigger on release only when Space was not used for dragging, pointer interaction, wheel zoom, another shortcut or window blur. Keep Space + drag panning and F fitting all objects. Do not fit while editing, composing, menus/dialogs, work or a gesture are active.
- Edit text directly inside its canvas frame. The fixed-size creation icon lives at the canvas left edge; a single selected text frame shows an adaptive settings icon just outside its lower-right corner. That icon opens a non-modal font/style card on the right, without a content textarea or a canvas-dimming overlay. Preserve in-progress text while switching between the frame and its style controls. Creation and settings icons have white silhouettes with transparent backgrounds and render in opaque white in normal, hover and expanded states.
- Canvas text uses fixed system SimHei (黑体), with no font picker. Use the supplied TextBold icon as an on/off bold button and three horizontal-line alignment icons in one row with a single active option. Keep line height and padding controls on the same row.
- Text content is Markdown source in the existing text YAML `content` field. Double-click edits source in the canvas textarea; finishing renders common GFM with Marked and DOMPurify. Share sanitized HTML, styles and resolved images between canvas and PNG export. Support headings, lists, quotes, links, raster images, code, tables and tasks; math/Mermaid are outside the requested scope. Retain local images referenced only from Markdown during resource cleanup, including other projects' text resources. Keep Markdown libraries bundled for offline use; web images require a connection and must not access private network addresses.
- Native `.hbr` is deterministic YAML plus same-directory `<stem>Resource/` files. Resource filenames are `Texture_<16 uppercase timestamp hash>_<8 uppercase content hash>.png` and `Text_<16 uppercase timestamp hash>_<8 uppercase content hash>.yaml`; hash segments are SHA256 prefixes using 0-9/A-F. Allocate each timestamp hash once and retain it across saves. Do not support historical resource filename formats in the application. All imported images normalize to compressed PNG; animated images use their first frame.
- Missing texture files display the bundled MissingTexture icon with uniform scaling inside their original frames. Missing text resources do not block opening the rest of the board. Saving and toolbar cleanup must preserve missing image/text reference entries in the .hbr, including the original text order and geometry; only manual editing may remove these entries. The toolbar cleanup action saves current edits and removes only orphan PNG/YAML files from the current project's resource directory. Do not recursively delete directories, follow resource symlinks, delete unrelated file types, or remove files referenced by other projects. Never remove prior resources before the updated project file is published successfully.
- Keep all current-project image bytes and decoded images in memory. Browser file operations use a typed HTTP client; each tab has an isolated server-side image store. Import images through Ctrl+V or drag and drop.
- Ctrl+C exports selected images/text together as a losslessly encoded PNG to the browser clipboard. Crop to selection bounds at 100% board scale, independent of viewport zoom/DPI, and flatten onto the current opaque canvas background. Exclude unselected objects and editor controls; preserve text layout, clipping and missing-image aspect ratio. Write only image/png, without internal text tokens. Ctrl+V imports the snapshot as one image; Ctrl+D duplicates editable objects, and Ctrl+X retains editable cut/paste. Preserve native copying inside text inputs. Reject oversized snapshots explicitly instead of silently downsampling. Use browser-native rendering/PNG compression without an additional snapshot library.
- Keep the repository root limited to `Code/`, `Dependencies/`, `Project/`, `.gitignore`, `README.md`, and `Start.cmd` (plus hidden `.git` metadata). The PowerShell launcher implementation lives in `Code/Module/Scripts/StartHybridRef.ps1`; generated state, logs and screenshots stay under `Code/Module/Runtime/`. Local dependency/cache files stay under `Dependencies/`. Demo: `Project/Demo/Demo.hbr` with `Project/Demo/DemoResource/`; the demo generator must refuse to overwrite an existing project.
- Windows and Edge are the assumed installed environment. Launch using bundled `Dependencies/Node/node.exe` only; do not fall back to PATH, Codex caches or npx. Keep normal launch offline. Use `Dependencies/Setup.cmd` to explicitly restore dependencies and `Dependencies/Pnpm.cmd` for development commands; preserve runtime licenses.
- Resolve the default `Project/` directory relative to the repository location. New projects request a name and immediately create `Project/<Name>/<Name>.hbr` plus `<Name>Resource/`, including the resource directory for an empty project.
- The “打开” dropdown starts with “新建项目”, followed by projects rescanned from `Project/` when opened. Creating a project requires a project-name confirmation. Project listing reads only immediate project files and does not load images, descend into resources or follow symbolic links.
- Do not show undo, redo or alignment toolbar buttons. Preserve Ctrl+Z for undo and Ctrl+Shift+Z / Ctrl+Y for redo. Ctrl+Left / Right / Up / Down Arrow push selected images in the corresponding direction. Keep plain H horizontal center, V vertical center, R push right, T push up and B push down; plain L is unbound. Require at least two selected images; do not activate while typing, menus are open, work or gestures are in progress, or Space is held. Reject modifier variants, composing input and key repeats.
- Directional push removes gaps along the requested axis, stopping edge-to-edge against another selected image with zero padding. Left/right changes only x; up/down changes only y. Preserve the other-axis positions, image sizes and stacking order. Rows or columns that do not intersect on the other axis do not block each other. Prevent selected-image overlap without flattening the selection into one row/column or forcing every image onto a shared edge. Each operation supports one-step undo/redo. Ctrl+Alt+Left / Right Arrow remain equal height / width and must not trigger directional push. The behavior follows the Push concept in the PureRef handbook; do not claim complete pixel-for-pixel PureRef compatibility.
- Equal width uses Ctrl+Alt+Right Arrow; equal height uses Ctrl+Alt+Left Arrow. Require at least two selected images, target their current mean width or height, and preserve each image's aspect ratio and center position. Both operations support undo/redo, have no toolbar buttons, and must not activate while typing or while a menu is open.
- Run `Dependencies/Pnpm.cmd typecheck`, `Dependencies/Pnpm.cmd test:run`, `Dependencies/Pnpm.cmd build`, `Dependencies/Pnpm.cmd exec playwright test` from the repository root. Validate portable environment changes with an OS-only PATH and a relocated checkout without modifying user projects.
- Preserve upstream licenses and third-party notices under `Code/Module`, and the provenance statement in `README.md`. Do not overwrite user-edited projects. Do not commit/push or publish unless requested.
- Use PascalCase for all project-owned source filenames, functions, methods, constants, variables, parameters, and local import/destructuring bindings. Active code is in `Code/Module/Source`, `Scripts`, and `E2E`; run `pnpm check:naming` (also part of `pnpm typecheck`). Preserve standard tooling filenames (`package.json`, `tsconfig.json`, `pnpm*.yaml`, `*.config.ts`), standard repository/legal filenames, external API property names, existing YAML/HTTP data keys, generated resource filenames, and archived/third-party material.
