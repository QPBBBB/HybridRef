# HybridRef

在浏览器中编辑的黑色图片与文本参考画布。React 前端提供无限画布，本地 Node.js 服务负责读写项目和资源，仅监听 `127.0.0.1`。

## 使用

Windows x64 下双击根目录 `Start.cmd`，启动器会构建缺失或过期代码、启动服务并打开系统浏览器。浏览器已打开时，在现有窗口中打开新标签页，不刷新已有画板。Node.js、pnpm 和所需库集中在 `Dependencies/`，无需另装开发环境；现成环境的启动、构建和测试均可离线运行。浏览器测试使用系统 Edge。

复制项目时请保留整个 `Dependencies/` 目录。`Code/Module/node_modules` 只是自动修复的目录链接，实际依赖位于 `Dependencies/Packages/node_modules`。依赖缺失或修改依赖清单后，运行 `Dependencies/Setup.cmd`；该显式安装步骤可能需要网络。普通启动不下载依赖，也不借用 PATH 或 Codex 中的 Node.js。

```powershell
.\Start.cmd                                  # 打开编辑器
.\Start.cmd -Demo                            # 打开 Project/Demo/Demo.hbr
.\Start.cmd 'D:\参考\TestRef.hbr'             # 打开指定项目，也可拖到启动器上
```

从“打开 → 新建项目”输入名称并确认，或直接拖入图片、按 Ctrl+V 粘贴截图后保存。“打开”菜单每次展开都会扫描仓库的 `Project/` 目录，选择项目即可切换。

拖动图片移动，框选或 Shift+单击多选，拖选框四角等比缩放。移动时提供边缘、中心吸附和辅助线，按 Alt 临时关闭吸附。

点击画布左侧“创建文本”图标添加说明，光标直接进入文本框；双击现有文本可原位编辑 Markdown 源码，完成后显示排版结果。Enter 换行，Ctrl+Enter 或点击框外完成输入，Ctrl+S 应用并保存项目，Esc 取消此次输入。字体由系统提供。

文本支持常用 GitHub 风格 Markdown：六级标题、粗体、斜体、删除线、有序与无序列表、嵌套列表、引用、链接、图片、行内代码、代码块、表格、分隔线和任务列表。普通换行也会保留。任务勾选在源码中修改 `[ ]` / `[x]`；Ctrl+单击打开网页或邮件链接。代码块保留缩进，暂不做语法着色；不包含公式与 Mermaid。

Markdown 图片支持项目目录内的相对路径（如 `Resource/Texture_….png`）、公网 HTTP/HTTPS 地址和内嵌图片。相对路径以 `.hbr` 所在目录为基准，另存到其他目录时需同时带上引用图片；网络图片需联网加载，当前页面成功加载后会缓存。图片等比适应文本框，加载失败显示带图片说明的占位提示。

单独选中文本时，右下角显示“字体设置”图标，点击打开右侧设置卡片。字体固定为系统黑体（SimHei），不能切换；加粗图标点击开启或关闭，三个并排的 34px 正方形横线按钮分别设置左对齐、居中、右对齐，选中状态会高亮。文字颜色与背景颜色并排显示；文字自身不透明度固定为 100%，不提供单独控件。“不透明度”统一控制文字、Markdown 内容与背景，新增文本默认为 100%，画布与 PNG 快照同步生效。字号与样式实时预览，行高与内边距放在同一行。卡片不遮罩画布，正文始终在文本框内编辑。左侧创建按钮保持固定屏幕大小；文本与箭头设置按钮共用白色齿轮图标，均为固定 24px 屏幕尺寸，不随对象大小或画布缩放改变。创建与设置图标使用不透明白色轮廓和透明背景，悬停及设置展开时也保持白色。

单独选中文字时，拖动四角自由调整文本框，文字自动换行且字号不变；框内放不下的内容会被裁切，可增大文本框。文本与图片支持混合选择、移动、吸附、复制、删除、撤销与重做。粘贴外部纯文本可直接创建文字对象。

选中图片或文本后按 Ctrl+C，将选中元素的合成快照以无损压缩 PNG 写入剪贴板。按所选元素的外接矩形裁切，沿用画布深黑底色，不保留透明度，不含选框、设置按钮或未选中的元素。快照按画板 100% 尺寸输出，不受当前缩放和屏幕 DPI 影响；字号、对齐、背景及透明效果与画布一致。Ctrl+V 可粘贴为一张图片；需要复制可编辑对象时使用 Ctrl+D。正在文本框或设置输入框中输入时，Ctrl+C 保持原生文字复制。超大选区会提示分批复制，不会自动降低分辨率。

“保存”按钮旁的 `*` 表示有未保存的内容、样式或布局修改，全部保存后消失。新建或切换项目时会提示未保存修改；关闭或刷新页面前也应先保存。每个标签页使用独立的图片缓存。

选中图片或文本后，四边中点外侧会显示圆形连接 handle，直接拖动任一 handle 即可创建连线。拖拽时显示其他图片和文本的四向 handle，靠近时高亮并吸附，松开后连接到对应边的中点，随目标移动或缩放。handle 大小与外侧间距保持屏幕尺寸，不随画布缩放改变；单击或轻微移动不会留下连线，Esc 取消本次拖拽。

也可点击左侧“创建箭头”，在画布上拖动创建自由折线箭头。单独选中箭头后拖动两端圆点调整或重新吸附连接，拖动中间方点调整折线位置。绘制及拖动端点时按住 Alt 可暂时关闭吸附。连线按连接点方向进入和离开对象；相互垂直的端口在方向允许时优先采用只拐一次的 L 形路径，例如从上侧竖直引出再水平接入左侧。不会自动避让其他对象，可手动移动折线；手动调整会随项目保存。

单独选中箭头时不显示 AABB 缩放框，显示起点、终点与折线 handle；白色齿轮位于箭头 AABB 正上方居中，打开右侧“线条设置”，可修改颜色、线宽及实线/虚线，支持实时预览、完成、取消和撤销重做。箭头也支持拖动、混合选择、空格适应选区、Ctrl+D 复制、剪切、删除及 Ctrl+C 黑底 PNG 快照。复制相连对象和箭头时，新箭头连接新副本；单独移动或复制箭头会解除对未选中对象的连接。删除连接对象保留箭头当前位置，撤销删除会恢复连接。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开 / 保存 / 另存为 | Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| 全选 / 剪切 / 粘贴 | Ctrl+A / Ctrl+X / Ctrl+V |
| 复制选中元素的 PNG 快照 | Ctrl+C |
| 复制所选对象 | Ctrl+D |
| 删除 | Delete / Backspace |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y |
| 向左 / 右 / 上 / 下贴紧 | Ctrl+对应方向箭头 |
| 向右 / 上 / 下贴紧 | R / T / B |
| 水平居中 / 垂直居中 | H / V |
| 等宽 / 等高 | Ctrl+Alt+右箭头 / Ctrl+Alt+左箭头 |
| 适应全部对象 | F |
| 放大并完整显示所选对象 | 轻按空格 |
| 平移 | 中键拖动，或空格+拖动 |
| 缩放 | 鼠标滚轮，或 + / − |

贴紧、居中、等宽和等高需要至少两个选中对象，输入、文本编辑或菜单打开时不触发。`L` 未绑定，`T` 保持向上贴紧。

选中一张或多张图片、文本后，轻按空格将所选内容等比放大或缩小到画布可用区域并居中，四周保留少量空隙；不修改对象的位置、尺寸和字号。没有选中内容时不改变视图。按住空格拖动仍然平移，松开后不会跳回选区；文字编辑时空格正常输入。

方向贴紧只移动指定轴，压缩间隙直到贴上其他选中对象，间距为零；另一轴、尺寸和层级不变，不相交的行或列互不阻挡。等宽/等高取所选对象当前宽度/高度的平均值，保持每个对象矩形框的比例和中心位置。混合选择后拖角按统一比例调整所有对象的矩形框；文本字号始终保持不变。这些操作均可撤销、重做。

## 项目文件

新建或首次保存未命名画板时，按名称创建以下结构，空白项目也会创建资源目录：

```text
Project/<Name>/
├─ <Name>.hbr
└─ Resource/
   ├─ Texture_A7C91E4B82D60F35_3A8F10C2.png
   ├─ Texture_A7C91E4B82D60F35_3A8F10C2.config
   ├─ Line_C82DA149B037E651_12F3A456.yaml
   ├─ Line_C82DA149B037E651_12F3A456.config
   └─ Text_B91DA743EE08265C_9D532DBC.yaml
```

`Project/` 相对于仓库位置解析。另存为也可选择其他目录；`.hbr` 与同目录的 `Resource/` 一起移动即可。`Project/Demo/Demo.hbr` 是可编辑的项目，不会在启动时重建。

`.hbr` 使用可 diff 的确定性 YAML，保存为 `formatVersion: 6`。图片和箭头条目只保存 `id` 和 `asset`，列表顺序决定各类对象的层级；图片与箭头的 `x`、`y`、`width`、`height` 存在资源同名的 `.config` 中。视口、文本布局与引用仍保存在 `.hbr` 中。可读取第 2 至 5 版并在保存时升级；旧服务会拒绝第 6 版，避免误写。第 1 版归档项目仍拒绝读取或覆盖。

`.config` 也是 YAML，格式如下。同一纹理的多个实例按 ID 分开记录，因此复制图片可以共享 PNG，同时拥有各自的位置和尺寸：

```yaml
format: "hybridref-texture"
formatVersion: 1
instances:
  image-1:
    x: 100
    y: 200
    width: 640
    height: 480
```

移动或缩放图片只更新对应的 `.config`；没有变化的项目、配置和 PNG 不会重写。不同对象的配置修改可以分别保存；同一对象被外部修改后，再保存本地冲突修改会提示重新打开画板。Agent 可直接编辑配置中的坐标，重新打开即可读取。配置缺失、格式无效或缺少对应 ID 时会提示对应对象的资源异常，不会猜测布局或删除引用；其他有效对象仍可打开。同目录另存为会为图片分配独立文件名，避免修改副本布局时影响原项目。

箭头使用 `Line_<16 位大写时间戳哈希>_<8 位大写 YAML 内容哈希>.yaml` 与同名 `.config`。YAML 格式为 `hybridref-line` 第 1 版，`arrow` 字段保存相对端点、折线方向与位置、颜色、线宽、虚线，以及两端的对象 ID/连接边/偏移。配置格式为 `hybridref-line-layout` 第 1 版，同样通过 `instances` 按箭头 ID 保存外接框。平移自由箭头只改配置；修改路径、样式或绑定时，时间戳哈希保持不变，内容哈希更新，并成对生成新 YAML/config，发布项目后删除无引用的旧文件。复制箭头及同目录另存为均使用独立文件名。资源 YAML 校验内容哈希，手动修改时需同步更新文件名、配套配置名与 `.hbr` 引用。

导入图片转为原分辨率的无损压缩 PNG，动画只取第一帧。图片与文本分别使用 `Texture_`、`Text_` 前缀，中间是毫秒时间戳 SHA256 的前 16 位，末尾是文件内容 SHA256 的前 8 位，均使用大写十六进制字符。名称分配后保持稳定，相同图片共用资源。

Markdown 源码及字体、字号、颜色、透明度、背景、段落和内边距保存在与 PNG 同目录的独立 YAML 资源中，源码写入原有 `content` 字段，文本资源格式仍为 `hybridref-text` 第 1 版。整体不透明度保存在顶层 `opacity`，旧资源缺少该字段时按 100% 显示；旧的文字、背景独立透明度字段仍可读取，但渲染时使用不透明的基础颜色，编辑完成后将这两个旧字段写为 1。`.hbr` 中的文本条目只保存 ID、资源路径和矩形位置尺寸。复制文本生成独立 ID，后续编辑互不影响。文本修改时更新内容哈希，项目保存成功后清除不再引用的旧资源，不保留历史资产。画布与 Ctrl+C 快照共用 Markdown 排版和基础文字样式。

图片内容和解码结果、文本和箭头内容均保留在当前会话。保存先写资源和配置，再原子替换项目 YAML，最后清除资源目录中未引用的 PNG/YAML 及同名配置。项目发布失败时回滚本次配置修改；重复保存同一状态不会产生布局差异。

资源哈希按原始字节检查。文本和箭头 YAML 若仅有 LF/CRLF 换行差异，会在统一换行后再次核对哈希；只有与文件名中的原哈希匹配才兼容读取，不忽略正文修改。保存也兼容这些换行差异，不重写已有资源。`Project/.gitattributes` 禁止 Git 自动转换资源文件的换行。

单个图片、文本、箭头或布局配置缺失、损坏及哈希不匹配，不会阻止其余内容打开。顶部可展开的提示列出异常资源及原因，保存后仍会显示。图片布局有效时使用内置占位图；无法读取的文本、箭头及缺少有效布局的图片暂不显示。修复文件后可重新打开或执行清理来恢复显示。普通保存与资源清理均保留异常资源的文件、项目引用、顺序及布局；另存为会原样带上可读取的异常文件和配套配置，缺失文件仍保留引用。项目本身格式无效、资源路径越界或经过符号链接仍会拒绝打开。

顶部“清理失效资源”会保存当前编辑，只清除当前 `Resource/` 里未引用的 PNG/YAML 及符合 `Texture_` / `Line_` 命名格式的 `.config` 文件。异常引用只能手动清理。清理不递归子目录，也不会删除其他项目仍引用的文件；仅由 Markdown 引用的本地图片同样会保留。若现存异常文本无法解析，无法确认其图片引用时，暂时保留资源目录内的 PNG，待修复文本后再清理。

## 开发入口

源码在 `Code/Module/`，环境和依赖在 `Dependencies/`，图标等素材在 `Code/Resource/`。目录说明、环境准备、构建和测试命令见[开发说明](Code/Module/README.md)与[本地环境说明](Dependencies/README.md)。项目自有文件、函数和变量使用 PascalCase，工具规定的名称与外部接口字段保留原样。
