# HybridRef

在浏览器中编辑的黑色图片与文本参考画布。React 前端提供无限画布，本地 Node.js 服务负责读写项目和资源，仅监听 `127.0.0.1`。

## 使用

Windows x64 下双击根目录 `Start.cmd`，启动器会构建缺失或过期代码、启动服务并打开系统浏览器。Node.js、pnpm 和所需库集中在 `Dependencies/`，无需另装开发环境；现成环境的启动、构建和测试均可离线运行。浏览器测试使用系统 Edge。

复制项目时请保留整个 `Dependencies/` 目录。`Code/Module/node_modules` 只是自动修复的目录链接，实际依赖位于 `Dependencies/Packages/node_modules`。依赖缺失或修改依赖清单后，运行 `Dependencies/Setup.cmd`；该显式安装步骤可能需要网络。普通启动不下载依赖，也不借用 PATH 或 Codex 中的 Node.js。

```powershell
.\Start.cmd                                  # 打开编辑器
.\Start.cmd -Demo                            # 打开 Project/Demo/Demo.hbr
.\Start.cmd 'D:\参考\TestRef.hbr'             # 打开指定项目，也可拖到启动器上
```

从“打开 → 新建项目”输入名称并确认，或直接拖入图片、按 Ctrl+V 粘贴截图后保存。“打开”菜单每次展开都会扫描仓库的 `Project/` 目录，选择项目即可切换。

拖动图片移动，框选或 Shift+单击多选，拖选框四角等比缩放。移动时提供边缘、中心吸附和辅助线，按 Alt 临时关闭吸附。

点击工具栏“文本”创建说明，双击现有文本打开编辑面板。面板可修改多行内容、字体、字号、字重、文字颜色及不透明度、背景颜色及不透明度、对齐、行距和内边距。Enter 换行，Ctrl+Enter 或“完成”应用编辑，Ctrl+S 应用并保存项目，Esc 取消此次编辑。字体由系统提供。

单独选中文字时，拖动四角自由调整文本框，文字自动换行且字号不变；框内放不下的内容会被裁切，可增大文本框。文本与图片支持混合选择、移动、吸附、复制、删除、撤销与重做。粘贴外部纯文本可直接创建文字对象。

“保存”按钮旁的 `*` 表示有未保存的内容、样式或布局修改，全部保存后消失。新建或切换项目时会提示未保存修改；关闭或刷新页面前也应先保存。每个标签页使用独立的图片缓存。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 打开 / 保存 / 另存为 | Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| 全选 / 复制 / 剪切 / 粘贴 | Ctrl+A / Ctrl+C / Ctrl+X / Ctrl+V |
| 复制所选对象 | Ctrl+D |
| 删除 | Delete / Backspace |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y |
| 向左 / 右 / 上 / 下贴紧 | Ctrl+对应方向箭头 |
| 向右 / 上 / 下贴紧 | R / T / B |
| 水平居中 / 垂直居中 | H / V |
| 等宽 / 等高 | Ctrl+Alt+右箭头 / Ctrl+Alt+左箭头 |
| 适应全部对象 | F |
| 平移 | 中键拖动，或空格+拖动 |
| 缩放 | 鼠标滚轮，或 + / − |

贴紧、居中、等宽和等高需要至少两个选中对象，输入、文本编辑或菜单打开时不触发。`L` 未绑定，`T` 保持向上贴紧。

方向贴紧只移动指定轴，压缩间隙直到贴上其他选中对象，间距为零；另一轴、尺寸和层级不变，不相交的行或列互不阻挡。等宽/等高取所选对象当前宽度/高度的平均值，保持每个对象矩形框的比例和中心位置。混合选择后拖角按统一比例调整所有对象的矩形框；文本字号始终保持不变。这些操作均可撤销、重做。

## 项目文件

新建或首次保存未命名画板时，按名称创建以下结构，空白项目也会创建资源目录：

```text
Project/<Name>/
├─ <Name>.hbr
└─ <Name>Resource/
   ├─ 1791870000000_3A8F10C2.png
   └─ Text_<文本ID>_<内容Hash>.yaml
```

`Project/` 相对于仓库位置解析。另存为也可选择其他目录；`.hbr` 与同目录的 `<文件名>Resource/` 一起移动即可。`Project/Demo/Demo.hbr` 是可编辑的项目，不会在启动时重建。

`.hbr` 使用可 diff 的确定性 YAML，当前格式为 `formatVersion: 3`，保存视口、对象布局与资源引用。已有第 2 版图片项目可直接打开，保存时升级；第 1 版归档项目仍拒绝读取或覆盖。

导入图片转为原分辨率的无损压缩 PNG，动画只取第一帧。图片资源名为 `13位Unix毫秒时间戳_8位大写Hash.png`，Hash 取 PNG 内容 SHA256 的前 8 位；名称分配后保持稳定，相同图片共用资源。

文本内容及字体、字号、颜色、透明度、背景、段落和内边距保存在与 PNG 同目录的独立 YAML 资源中，文本资源格式为 `hybridref-text` 第 1 版。`.hbr` 中的文本条目只保存 ID、资源路径和矩形位置尺寸。复制文本生成独立 ID，后续编辑互不影响。文本修改后写入新的内容版本资源，再更新项目引用，上一次保存使用的资源保持不变。

图片内容和解码结果、文本内容均缓存在内存。保存先写资源，再原子替换项目 YAML；不会自动清除未引用的资源。重复保存同一状态不会产生布局差异。
